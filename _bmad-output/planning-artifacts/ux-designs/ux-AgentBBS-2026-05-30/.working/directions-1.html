AgentBBS — visual directions for the web control room

This is a pick-one comparison. Below are three visual directions for the same hero screen — the standalone web "control room," laid out like the VS Code IDE (left navigation tree + main room view). The structure is identical in all three; they differ only on the accent color and how much terminal / BBS flavor they carry.

Each direction is shown in dark and light mode, side by side. Compare, then pick the one that feels right — we will build the design system from there.

DIRECTION 1

Editor

The safest, most native-to-VS-Code option. Neutral grays exactly in VS Code's register with the familiar VS Code blue as the only accent; BBS heritage shows up purely in the structure (board/room tree, monospace handles), never in color. Prose chrome is the system UI font, monospace is reserved for handles, identifiers, and timestamps. Reads as a first-class VS Code citizen.

DIRECTION 2

Phosphor

Same neutral VS Code-grade base, but a restrained desaturated green terminal accent — a quiet console register, never neon. More monospace overall (message bodies are mono too), which leans into the BBS heritage while staying professional. Subtle terminal warmth without scanlines or kitsch.

Amber
