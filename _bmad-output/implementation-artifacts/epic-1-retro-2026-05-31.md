## Challenges / Lessons

- **[PRIMARY] Toolchain provisioning surfaced mid-story, not at epic start.** Machine had Node 22 / pnpm 10 vs the committed Node 24 / pnpm 11.3. The dev stage of Story 1.1 correctly halted, but the gap should have been caught during epic pre-flight. → **Action A (adopted as Rule 9).**
- **Native-build friction under pnpm 11.3.** `unrs-resolver` (1.2) and `better-sqlite3` (1.4) both needed `allowBuilds` entries or `pnpm install` warned/failed. Pattern now established; MCP SDK (Epic 2) is not native, so likely unaffected.
- **LF/CRLF churn.** Every commit emits "LF will be replaced by CRLF" warnings — no `.gitattributes`. Cosmetic but noisy. → **Action C (Epic 2 prep task).**
- **Lead smoke gate scope.** Early per-story smokes ran build+typecheck+lint+test but not `format`, which let the Story 1.5 format break reach Story 1.6 before QA caught it. Lead adopted running the full gate set in smokes as a working practice for the rest of the epic; **not** codified as a formal rule (Project Lead's call — proposed Action B declined).
